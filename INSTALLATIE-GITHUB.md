# Installatie Basic RT PRO 3.8 BETA (GitHub Pages)

**Snelste manier:**
1. Download `Basic-RT-PRO-3.8-SNELLE-UPDATE.zip` en pak het ZIP-bestand uit.
2. Open de GitHub-repository `VT-App` > **Add file** > **Upload files**.
3. Upload `index.html`, `app.mjs`, `rt-core.mjs`, `rt-curves.mjs`, `rt-curves.json`, `manifest.webmanifest`, `sw.js`, `README-3.8.md`, `test-3.8.mjs`. Vervang bestanden op dezelfde paden, **niet** in een extra map.
4. Kies **Commit changes**. Bezoek je GitHub Pages-adres. Op iPhone eventueel Safari vernieuwen; open zo nodig een privévenster als de offline-cache nog 3.7 toont.
5. Controleer Se-75 D4 10mm, 40Ci, 800mm, D2,0 = `00:14:28` en Ir-192 D4 20mm, zelfde condities = `00:11:07`.

**LET OP:** softwarevergelijkingsmodel, niet vrijgegeven voor echte RT-belichtingen. Rekenmodel blokkeert buiten gecontroleerde toepassingsgebieden.
